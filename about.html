관계 콘텐츠 플랫폼

연결운은 사람과 사람, 사람과 반려동물, 가족 전체의 관계를 다양한 무료·유료 콘텐츠로 연결하는 정적 웹 플랫폼입니다.

💞

사람 관계

1:1 궁합, 모임 관계도, 연락·재회 흐름, A/B/C 비교.

🐾

반려동물 관계

DOG DNA, CAT DNA, 보호자·집사 궁합, 우리집 관계도.

📚

검색 콘텐츠

60갑자, 견종·묘종 백과, 꿈해몽으로 검색 유입을 만듭니다.

AI 비용 없이 확장

핵심 계산과 문장 생성은 규칙·데이터·템플릿을 사용해 LLM API 호출 없이 동작합니다. 사용자가 늘어날 때 분석 한 건마다 생성형 AI 비용이 붙지 않는 구조를 지향합니다.

무료와 유료를 분리

오늘운, 백과, 꿈해몽처럼 반복 방문하거나 검색으로 들어오는 콘텐츠는 무료와 광고에 적합합니다. 반면 상세 궁합, 연락·재회 리포트, 여러 사람 비교, 우리집 상세 관계도처럼 개인화가 강한 결과는 단건 결제에 적합하도록 구분했습니다.

결과를 어떻게 봐야 하나

사주 점수, 일주 성향, 꿈해몽, 반려동물 DNA는 모두 오락·참고용 콘텐츠입니다. 사람의 실제 마음이나 미래 행동을 알 수 없고, 품종만으로 반려동물의 성격을 결정할 수도 없습니다. 숫자는 이해하기 쉬운 상대지표이지 전통적으로 정해진 절대점수가 아닙니다.
